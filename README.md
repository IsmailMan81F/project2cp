# ESP32 Monitor

Full-stack web app to monitor ESP32 sensors via Home Assistant. Displays temperature data and provides an AI assistant for smart home insights.

## Current Status

**Frontend (done)** — React + Vite + Tailwind. Landing page and dashboard with placeholders for sensor data and AI chat.

**Backend (planned)** — Node.js + Express. Will connect to Home Assistant and serve the API.

## Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:5173.
